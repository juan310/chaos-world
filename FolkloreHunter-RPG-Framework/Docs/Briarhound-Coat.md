# Briarhound coat (from the Codex combat prototype)

The Briarhound model (`Models/Briarhound.fbx`) is the same file in both projects. Its reconstructed atlas has smeared
fur on the legs, chest, underside and tail; the Codex prototype repaired that with its **coat repair V2**, now used here
too (copied unchanged from `FolkloreHunter-CombatTest-Codex`, which was only read):

- `Assets/Resources/Monsters/Briarhound_FurMeshV2.asset`: the same mesh (positions, normals, UVs, weights identical to
  the imported FBX) with rest positions, rest normals and a coat mask in spare vertex channels.
- `Assets/Resources/Monsters/Briarhound_FurV2.mat` and `Briarhound_fur_detail_v2.png`: the fur material and its tile.
- `Assets/Framework/Resources/Shaders/BriarhoundFurRepair.shader`: lays the tile (three projections from the rest
  positions, so it moves with the skin) over the masked coat, tinted charcoal, cream chest and tan legs; the face,
  ears, saddle, bags, straps and claws keep the original atlas.

`CharacterFactory.BriarCoat` swaps the mesh in only when its vertex count matches the imported one, and the proving run
checks the hound wears it. Provenance (from Codex's `Docs/Briarhound/TextureRepair/README.md`): the fur tile was
generated by Codex's built-in image tool (no paid service); the body, atlas and gear are the existing reconstructed
asset. The coat repair does not change the fur geometry or the gear's stretched UVs.

The hound's motion stays this game's own (`HoundCompanion`). MotionBricks is a human-body model (its SOMA skeleton),
so it cannot animate a quadruped.
